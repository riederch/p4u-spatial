# P4U Spatial

P4U Spatial provides the Home Assistant deployment of the open spatial bridge for XR, GIS and interoperable spatial data.

## Version 0.0.1

Version 0.0.1 replaces the Hello World bootstrap with the real P4U Spatial Bridge.

It currently provides:

- Core discovery,
- device pairing/session support,
- the XR bridge API,
- Git-profile-backed Spatial Read,
- persistent state and repository storage under Home Assistant app storage,
- port 8787 for the bridge HTTP API.

The project is still pre-release and the app remains configured for manual startup.
